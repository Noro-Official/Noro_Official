# Noro Curriculum

Welcome to the official **Noro Curriculum** — a growing set of notebooks, labs, and conceptual demos for teaching the deep logic of modern systems.

Unlike tool-specific tutorials (see [OpenQStack](https://github.com/noro-org/OQS)), this curriculum is focused on:

- Learning from **first principles**
- Visualizing **stabilizers, noise, and feedback**
- Building conceptual fluency in **error correction and structure**

### Contents

- `getting_started.ipynb` – Noro’s teaching philosophy in practice  
- `qec_intro/` – The logic of stabilizers, syndromes, and recovery  
- `noise_models/` – Bit flip, depolarizing, and compound channels  
- `surface_codes/` – Intro to lattice-based QEC (coming soon)

---

All notebooks are designed to run locally with Python 3.8+, NumPy, and Matplotlib.

> This curriculum is not bound to a single tool. It is the pedagogical backbone of Noro.

For platform-specific demos, see [OpenQStack](https://github.com/noro-org/OQS).
